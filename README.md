# 超级飞侠自然拼读图鉴

> 一个基于纯前端技术栈的交互式图鉴网页，帮助儿童通过喜爱的动画角色学习自然拼读（Phonics）。

---

## 项目概述

本项目是一个单文件 HTML 应用，展示《超级飞侠》动画中的 47 位角色，并为其中 41 位角色绑定自然拼读音标与发音音频。用户可以通过搜索、分类筛选浏览角色，点击卡片查看详情，并点击胶囊按钮播放对应音标发音。

**核心特点：**
- 响应式设计：手机端 2 列，电脑端 4 列
- 实时搜索：输入即过滤，无需点击搜索按钮
- 音频播放：右上角胶囊按钮，播放中显示绿色脉冲动画
- 容错设计：图片缺失时自动显示占位图，音频缺失时静默失败

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 结构 | HTML5 | 单文件 `index.html` |
| 样式 | CSS3 | Flexbox + Grid + 媒体查询 |
| 逻辑 | Vanilla JS | 无框架，无构建工具 |
| 资源 | 本地静态文件 | 图片 + 音频 |

**无需安装任何依赖**，双击 `index.html` 即可在浏览器运行。

## 文件结构

```
my-pokedex/
├── index.html              # 主文件（HTML + CSS + JS + 数据）
├── images/                 # 角色图片（47张）
│   ├── 1.webp              # 乐迪
│   ├── 2.webp              # 小爱
│   └── ... 47.webp         # 腕腕
├── audio/                  # 自然拼读音频（41条）
│   ├── 1.mp3               # 乐迪 /s/
│   ├── 2.mp3               # 小爱 /æ/
│   └── ... 41.mp3          # 小翼 /ɑː/
└── README.md               # 本文档
```

**命名规则：**
- 图片：`{id}.webp`，id 范围 1-47，与角色严格一一对应
- 音频：`{id}.mp3`，仅 1-41 需要，42-47 无音标故无需音频

5. **排序规则**：按人气/出场频率排列，不可随意更改 id 顺序
6. **音标规则**：01-41 有 phonics 字段，42-47 无，胶囊按钮据此渲染

**推荐迁移方式**：
- 将 `index.html` 内容复制给新 AI，说明"基于这个单文件继续开发"

## 注意事项

1. **图片格式**：统一使用 `.webp`，兼容性优于 `.png`，体积小于 `.jpg`
2. **音频格式**：统一使用 `.mp3`，时长控制在 5 秒以内，单文件建议 < 500KB
3. **id 不可随意变更**：id 与图片、音频、音标严格绑定，变更需同步重命名所有资源文件
4. **浏览器兼容**：现代浏览器（Chrome/Edge/Safari/Firefox 最新版）均支持，IE 不支持
